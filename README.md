# CareerSync 🚀

An intelligent, modern career and job application tracking platform designed to streamline your job search, organize application pipelines, and keep you on top of your career goals.

---

## 🌟 Features

* **Application Pipeline Tracker:** Visually manage your job applications across stages (Applied, Interviewing, Offer, Rejected) using an intuitive interface.
* **Smart Analytics & Insights:** Track response rates, application trends, and overall success metrics via a clean dashboard.
* **Resume & Document Management:** Keep track of tailored resumes and cover letters associated with specific roles.
* **Reminders & Follow-ups:** Never miss a follow-up or interview deadline with built-in scheduling and task tracking.
* **Responsive & Modern UI:** Built with a sleek, mobile-friendly interface optimized for speed and ease of use.

---

## 🛠️ Tech Stack

* **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
* **Backend / API:** Next.js Server Actions / API Routes
* **Database & ORM:** PostgreSQL / SQLite
* **Authentication:** NextAuth.js
* **Deployment:** Vercel / Render
